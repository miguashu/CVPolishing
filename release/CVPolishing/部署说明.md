# CVPolishing 一键部署说明

AI 简历精修 · 智能面试 · 会员系统。多 Agent 协作的简历优化平台：联网检索 → 优化 → 评分 → 思考诊断 → 细节精修 → 监督终裁，支持面试问答生成、长期记忆（向量召回）与 PDF 导出。

## 一、环境要求

| 组件 | 要求 | 说明 |
|---|---|---|
| Python | 3.10+ | 需勾选「Add Python to PATH」 |
| MySQL | 5.7 / 8.0 | 本机安装并加入 PATH，或用 Docker 方式（见下文） |
| Ollama | 可选但推荐 | 长期记忆向量召回用，需 `ollama pull bge-m3` |
| 大模型 API Key | 必填 | OpenAI 兼容接口，在 `.env` 的 `LLM_API_KEY` 填写 |

## 二、快速开始（Windows 本地版）

1. 解压本压缩包到任意目录；
2. 双击运行 `start.bat`；
3. 首次运行会自动复制 `.env.example` 为 `.env`，**打开 `.env` 填入你的配置**（至少填 `LLM_API_KEY`，并按需修改 `DB_PASSWORD`）；
4. 再次运行 `start.bat`，脚本会自动：
   - 安装 Python 依赖
   - 初始化数据库（建库建表、导入自带演示数据、创建种子账号）
   - 启动服务
5. 浏览器访问 **http://localhost:5090**

默认管理员账号：`admin / admin123!`（首次登录后请尽快修改）。

## 三、Docker 方式（无需本机 MySQL）

1. 安装 Docker Desktop；
2. 双击 `deploy.bat`（或 Linux 下 `bash deploy.sh`）；
3. 脚本会构建「应用 + MySQL」容器并启动，访问 http://localhost:5090。

> 注意：Docker 方式会挂载本地 `data/` 目录，`db_init.sql` 演示数据需手动导入容器 MySQL：
> ```
> docker compose cp db_init.sql cvpolishing-db:/tmp/db_init.sql
> docker compose exec db sh -c "mysql -uroot -p${DB_PASSWORD:-root} < /tmp/db_init.sql"
> ```

## 四、配置说明（.env 关键项）

- `LLM_API_BASE` / `LLM_API_KEY` / `LLM_MODEL`：大模型问答引擎（OpenAI 兼容）。
- `DB_HOST` / `DB_PORT` / `DB_USER` / `DB_PASSWORD` / `DB_NAME`：MySQL 连接（默认 127.0.0.1:3306 / root / root / cvpolishing）。
- `EMBEDDING_PROVIDER` / `EMBEDDING_API_BASE` / `EMBEDDING_MODEL`：向量召回（默认本地 Ollama bge-m3，无需 key）。
- `VIP_ACTIVATION_CODE`：会员激活码（留空关闭入口）。
- `ADMIN_USERS`：管理员账号（逗号分隔，默认 admin）。
- `SECRET_KEY`：会话签名密钥，**生产环境务必改成随机强密钥**。
- 支付通道：`PAY_PROVIDER`（alipay 直连 / aggregate 第三方聚合），相关密钥在 `.env` 中按注释填写。

## 五、自带演示数据

发布包已内置你的本地演示数据（通过 `db_init.sql` 与 `data/memory.json` 携带）：

- **面试长期记忆**：112 条面试问答 + 向量（归属 admin，登录即可见）；
- **简历样例**：1 份优化示例；
- **提示词配置**：`data/prompts.json`（与代码同源，可在线调整）。

敏感信息已全部脱敏：真实 API Key、账号密码哈希、会话、订单、邀请码均不随包分发，接收方需自行配置自己的 `LLM_API_KEY`。

## 六、常见问题

- **端口被占用**：修改 `.env` 的 `PORT`（默认 5090）。
- **向量检索无结果**：确认本地 Ollama 已运行且 `ollama pull bge-m3`。
- **「未配置 LLM_API_KEY」**：检查 `.env` 中 `LLM_API_KEY` 是否填写。
- **MySQL 连接失败**：确认 MySQL 服务已启动、端口与 `.env` 一致。
